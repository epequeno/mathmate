# Implementation Plan: Math Answer Quality Tools

## 1) Goal
Add math-specific quality controls that reduce common tutoring errors and improve learning outcomes.

Primary capabilities:
1. Step Checker mode
2. Final-answer verification gate
3. Common-mistake detector

---

## 2) Product Surface

## 2.1 User-visible features
- Toggleable **Step Checker** for line-by-line validation of student work
- Optional **"Verify before final answer"** policy
- Inline **Mistake Alerts** (sign errors, algebraic slips, domain/unit checks)

## 2.2 Where features live
- Mode picker / quick actions in chat toolbar
- Context panel diagnostics section
- Optional slash commands for targeted checks (future)

---

## 3) System Design

Create a lightweight post-processing pipeline for assistant drafts before final render:

1. Draft generated by model
2. Quality checks run (rule-based first)
3. If check fails:
   - ask model for self-repair with explicit constraints, or
   - append warning/uncertainty note
4. Emit final assistant content + quality metadata

### New module
- `Sources/MathMate/Quality/MathQualityEngine.swift`

### Quality metadata
Add per-message metadata object:
- checks run
- pass/fail/warn
- detected issues list
- optional repaired flag

---

## 4) Feature Specs

## 4.1 Step Checker
Input:
- user-submitted steps (text/math)
- target problem statement (if available)

Output:
- structured report:
  - `correct_steps`
  - `first_error_step`
  - `error_type`
  - `hint`
  - `next_action`

Implementation:
- Rule heuristics for simple transforms (sign flips, distributive expansion, derivative forms)
- Model-assisted explanation for natural-language feedback

## 4.2 Final-Answer Verification Gate
Before final answer is shown, validate:
- algebraic consistency (if expression-based)
- domain constraints (e.g., division by zero, sqrt domain)
- units (if unit-bearing prompt)
- numerical sanity checks

If gate fails:
- request compact correction from model with explicit failure reasons
- annotate response with "verified" or "needs caution"

## 4.3 Common-Mistake Detector
Detector categories (MVP):
- sign/distribution errors
- dropped exponent/parentheses
- derivative/integral rule misuse
- equation-solving extraneous root risk

Attach short warning chips + hint text.
