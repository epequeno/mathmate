# Dev Log — 2026-06-09

## PDF Viewer Navigation, Caching, Capture Region, and Zoom/Fit Width Fix

Improved the Book tab PDF viewer so users can navigate textbooks more directly, revisit the Book tab faster, capture page regions more reliably, and view pages at the intended scale.

### Changes
- **`mathmate/src/pages/BookPage.tsx`**
  - Added a small module-level Blob URL cache keyed by project/textbook path. Returning to the Book tab now reuses the existing object URL instead of re-reading and base64-decoding the entire PDF when possible.
  - Keeps only a few recent cached PDFs and revokes older object URLs.
- **`mathmate/src/hooks/usePdfRenderer.ts`**
  - Corrected HiDPI pdf.js canvas rendering by resetting the canvas context transform to identity before each render and passing the device-pixel-ratio transform only to pdf.js. This avoids double-applying DPR scaling.
  - Added embedded PDF outline/bookmark loading with page-number resolution for named and explicit destinations.
  - Added a small module-level pdf.js document cache so revisiting the Book tab can reuse the parsed document proxy and resolved bookmarks instead of parsing the PDF again.
- **`mathmate/src/hooks/usePdfRegionSelect.ts`**
  - Exposed the overlay ref and a programmatic `captureSelection(rect)` helper so capture can be initiated by explicit UI rather than only pointer-drag gestures.
- **`mathmate/src/components/PdfViewer.tsx`**
  - Added a Bookmarks toolbar button and toggleable sidebar that displays the PDF outline tree when available.
  - Bookmark rows navigate directly to resolved page destinations.
  - Reworked the page jump field into a controlled input with a Go button, Enter-to-submit, Escape-to-clear, and out-of-range validation.
  - Added Capture Region mode: users click a toolbar button, move/resize a visible capture box, then choose Take Screenshot or Cancel.

- **`docs/mathmate/00_Project_Management/Roadmap.md`** — Marked **PDF Viewer Tab** as completed (was still `[ ]` despite being fully implemented).
- **`docs/mathmate/Implementation_PDFViewerTab.md`** — Updated status from "Planned" to "Complete".

## Textbook Content Integration — Phase 1 Implementation

Full-text search and agent-proactive textbook retrieval. Users can ask the AI tutor about specific sections/exercises from their textbook, and the agent can search the indexed text to find relevant content.

### Backend (Rust)
- **`mathmate/src-tauri/src/textbook_index.rs`** (new) — `PageContent`, `TextbookIndex`, `TextbookIndexMeta`, `SearchResult` types. Index save/load from `~/.mathmate/textbooks/{id}_index.json`, keyword frequency scoring with position bonus, snippet extraction, stable textbook ID derivation via SHA-256 path hash. 11 unit tests all passing.
- **`mathmate/src-tauri/src/tools/textbook_search.rs`** (new) — OpenAI-compatible `search_textbook` tool definition and executor. Resolves project → textbook path → index → search → formatted results. Returns `{ found, query, results: [{page, snippet, relevance_score}], message }`. Handles no-project, no-textbook, not-indexed, indexing-in-progress, and empty-results cases gracefully.
- **`mathmate/src-tauri/src/tools/mod.rs`** — Registered `textbook_search` module, added to tool definitions (now 8 tools total), added dispatch arm for `"search_textbook"`, updated signatures/tests for `project_id` parameter.
- **`mathmate/src-tauri/src/lib.rs`** — Registered `mod textbook_index`. Added three Tauri commands: `index_textbook_pages` (save page batches), `get_textbook_index_status` (cache check), `derive_textbook_id` (stable ID from path). Registered all in invoke handler.

### Frontend (TypeScript/React)
- **`mathmate/src/hooks/useTextbookIndexer.ts`** (new) — React hook that extracts text from pdf.js document page-by-page in batches of 10, sends results to `index_textbook_pages` Rust command. Auto-starts when a textbook is first opened, checks existing index status before extraction, reports progress.
- **`mathmate/src/hooks/usePdfRenderer.ts`** — Exposed `pdfDocument: PDFDocumentProxy | null` in the return type so the indexer can access the pdf.js document proxy.
- **`mathmate/src/components/PdfViewer.tsx`** — Added `textbookId` and `textbookTitle` props. Integrates `useTextbookIndexer` hook. Shows indexing progress indicator (animated dot + "Indexing… 42/356") and "✓ Search ready" status in the toolbar.
- **`mathmate/src/pages/BookPage.tsx`** — Derives stable textbook ID by calling `derive_textbook_id` Tauri command after loading the PDF. Passes `textbookId` to PdfViewer.
- **`mathmate/src/stores/chatStore.ts`** — Injects textbook context into system prompt when project has a `textbook_path` set: instructs the AI to use `search_textbook` for section/exercise/topic queries.
