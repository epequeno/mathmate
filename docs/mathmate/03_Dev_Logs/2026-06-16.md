# Book Tab PDF Streaming — Implementation

## Summary
Replaced the base64/Blob first-load path with a local loopback HTTP range server (Axum on tokio), letting pdf.js use its native byte-range loading for textbook PDFs. First page render for large textbooks is now substantially faster on cold launch.

## Changed

### Rust — New `book_stream` module
- **`mathmate-v2/src-tauri/src/book_stream.rs`** — `BookStreamServer` starts an Axum HTTP server on `127.0.0.1:<ephemeral-port>` during Tauri app `.setup()`. Per-process 32-char random token required as query param. `GET /book/{project_id}?token=...&v=...` serves PDFs with full `Range`/`206 Partial Content` support. `OPTIONS` returns CORS preflight. `PathScope::guard` runs on every request with the project ID.
- `parse_range()` helper with 20 unit tests (single ranges, suffix, overflow, unsatisfiable).
- Responses stream via `tokio_util::io::ReaderStream` — no full-file buffer for `200` or `206`.

### Rust — lib.rs / services/mod.rs
- Added `.setup()` hook that reads `AppServices.base_dir`, spawns the book stream server, and manages it as Tauri state.
- Added `get_book_stream_info` Tauri command (returns `{ origin, token }`).
- Added `pub base_dir: PathBuf` to `AppServices`.

### Rust — Cargo.toml
- New deps: `axum = "0.8"`, `tokio` (features: net, sync, fs, io-util), `tokio-util` (features: io).

### Frontend — API wrapper (`src/lib/api/textbook.ts`)
- Added `BookStreamInfo`, `getBookStreamInfo()`, `projectTextbookStreamUrl()`, `textbookPathRevision()`.
- Marked `Textbook.readProjectTextbook` as `@deprecated`.

### Frontend — BookPage.tsx
- Removed `pdfUrlCache`, `CachedPdf`, `cacheKeyForProject`, `prunePdfCache`, `atob`/byte loop, Blob URL creation.
- New effect fetches stream info once per session (module-level promise), builds streaming URL with revision hash.
- Preserves `textbookId` derivation, loading/error/empty states.

### Frontend — useTextbookIndexer.ts
- Auto-indexing delay increased from 500ms → 2000ms to let the first page render before range-request-heavy indexing begins.

### CSP (tauri.conf.json)
- Added `http://127.0.0.1:*` to `connect-src`.

## Key decisions
- **Axum 0.8** chosen for clean API and full HTTP/1.1 support (hyper 1.x).
- **Query-param token** (not header) avoids CORS preflight for every range request. Visible in DevTools but per-session, unguessable.
- **HEAD handled by Axum implicitly** (no explicit head handler).
- `read_project_textbook` retained but deprecated; zero remaining callers in BookPage.
