# 2026-07-02 — Catalog Addition: Evans & Rosenthal + Calculus in Context

## Summary

Added two free, open-access textbook entries to the embedded library catalog
(`mathmate/src-tauri/resources/textbook-catalog.json`).

## Changes

### Catalog additions

- **Probability and Statistics - The Science of Uncertainty (2nd ed.)** —
  Michael J. Evans & Jeffrey S. Rosenthal (University of Toronto).
  Comprehensive upper-level mathematical-statistics text: probability models,
  random variables, expectation, sampling distributions, then likelihood,
  Bayesian, and optimal inference, model checking, regression, and stochastic
  processes. Single-PDF or per-chapter download plus a solutions manual.
  License: free (copy/distribute without alteration, with attribution, no
  charge). Subject: `statistics`. PDF ~18.4 MB.
  - Landing: https://utstat.toronto.edu/mikevans/jeffrosenthal/
  - PDF: https://utstat.toronto.edu/mikevans/jeffrosenthal/book.pdf

- **Calculus in Context** — James Callahan, David Cox, Kenneth Hoffman,
  Donal O'Shea, Harriet Pollatsek, Lester Senechal (Five College Calculus
  Project, Smith College). Reform-calculus text emphasizing applications and
  context; covers single-variable calculus (with differential equations
  introduced early) through multivariable functions, dynamical systems, and
  series. Full text downloadable as one PDF or in Calculus I / II splits.
  License: free. Subject: `calculus`. PDF ~8.4 MB, ~845 pp.
  - Landing: https://www.science.smith.edu/~callahan/intromine.html
  - PDF: https://www.science.smith.edu/~callahan/cic/book.pdf

### Note on the second URL

The user-supplied URL `https://www.science.smith.edu/~callahan/intromine.html`
has a filename suggesting "intro to data mining," but the page is in fact the
landing page for *Calculus in Context*. Verified against the page title, author
list, and the parent directory listing. Added as a `calculus` resource
accordingly.

### Build note

The catalog is `include_str!`-ed at compile time in
`textbook_catalog.rs`, so a Rust recompile (`npm run tauri dev` restart or
`cargo check`) is required for the new entries to appear at runtime. No code
changes were needed.
