### HintLadderWidget component

New React component (`src/components/chat/HintLadderWidget.tsx` + `.module.css`):

**States:**
1. Problem shown (collapsible) + attempt textarea (required before hint unlock)
2. "Submit attempt & unlock hints" button → triggers generation of 4 hints
3. Hint strip: H1–H4 chips, only the next one is clickable, remaining are locked
4. Each hint reveals progressively (meta-strategy → structural → key insight → solution sketch)
5. "I solved it!" / "I'm stuck" outcome buttons save to session header

**Features:**
- Loading dots during hint generation
- Error display if generation fails
- Outcome badge after completion
- All 4 hints generated in one call, revealed lazily
