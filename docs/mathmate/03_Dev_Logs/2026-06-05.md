## PDF → Vault Import

New feature for parsing PDF textbook outlines (bookmarks/TOC) and auto-generating vault study notes.

### Changes
- **`mathmate-v2/src-tauri/Cargo.toml`** — added `lopdf` (0.34) and `indexmap` (2) for PDF parsing.
- **`mathmate-v2/src-tauri/src/pdf_import.rs`** (new) — `extract_pdf_toc()` traverses the PDF document outline tree via the `/Outlines` → `/First` → `/Next` linked list, extracting titles and page numbers for each bookmark entry. `import_pdf_toc()` generates vault files: chapter folders under `Chapters/`, section `.md` notes with study templates, `PROGRESS.md` with a chapter/section check-off table, and a textbook reference in `Home.md`. Subsection-level entries are aggregated into chapter overview files.
- **`mathmate-v2/src-tauri/src/lib.rs`** — registered `extract_pdf_toc` and `import_pdf_toc` Tauri commands.
- **`mathmate-v2/src/components/ProjectSettingsPanel.tsx`** — Added "Import PDF Structure" section that appears when both `textbook_path` and `vault_path` are set. Users click "Parse PDF table of contents", see a scrollable checkbox list of extracted chapters/sections with page numbers and nesting, then click "Generate N vault notes" to create the files.

### Architecture
```
PDF outline → TocEntry[] → selected TocEntry[] → vault files
                   │
                   ├─ level 0 → Chapters/XX - Chapter name/  (folder)
                   ├─ level 1 → Chapters/.../XX - Section.md  (note with template)
                   └─ level 2+ → Chapters/.../XX - Overview.md  (appended subheadings)
```
