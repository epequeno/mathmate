# Dev Log — 2026-06-25

## Catalog Addition: Discovering the Art of Mathematics (11 volumes)

Added eleven free textbook entries to `mathmate-v2/src-tauri/resources/textbook-catalog.json`
(catalog now 48 → 59 entries).

### Source
The Discovering the Art of Mathematics (DAoM) project at Westfield State University
(`https://www.artofmathematics.org`), an inquiry-based-learning (IBL) liberal-arts
mathematics series by **Julian F. Fleron**, **Philip K. Hotchkiss**, **Volker Ecke**, and
**Christine von Renesse**. The user-supplied entry point was the topic index
`https://www.artofmathematics.org/books/topics`; the library landing page is
`https://www.artofmathematics.org/books`.

### Scope decision
- Initially added as a single library-level entry. On review, replaced that single entry
  with **11 individual per-volume entries** to match the catalog's existing per-book
  granularity (OpenStax, Huber, etc.) and to give each volume its own direct PDF, page
  count, file size, subject, and cover thumbnail. Listing both ways was rejected to avoid
  duplicate-counting and filter overlap.
- The 11 volumes are all **liberal-arts mathematics** books (each explores a genuine math
  topic through a thematic lens — e.g. "Dance"/"Music"/"Art & Sculpture" are
  math-through-dance/music/art, not dance/music textbooks). The most logic-adjacent volume
  is *Truth, Reasoning, Certainty, & Proof* (proofs/foundations).
- A separate "Algebra" PDF assembled from the topic index (`/sites/default/files/blog-posts/algebra.pdf`)
  exists on the site but is **not** one of the 11 core library volumes, so it was not added.

### Verification performed
- Confirmed the series was absent from the catalog (grepped `artofmathematics`,
  `Art of Mathematics`, `Fleron`, `Hotchkiss`, `Ecke`, `von Renesse` — no prior hits).
- Verified each book page and its canonical "Download Book" PDF return HTTP 200; captured
  `content-length` for each PDF via `curl -sI -L`.
- Downloaded each PDF and captured page counts via `pdfinfo`.
- Verified cover thumbnail JPGs resolve (HTTP 200, `image/jpeg`) — used the
  `0N-daom-...-book-cover.jpg` images as `thumbnail_url`.
- License: the books are freely downloadable but carry only a plain
  `© 2008-2026 Julian Fleron, Phil Hotchkiss, Volker Ecke, & Christine von Renesse` notice;
  no Creative Commons (or other open) license is stated anywhere on the site. Per the
  catalog taxonomy, license `free` was used.

### Subject mapping
The UI's `SUBJECT_LABELS`/`SUBJECT_COLORS` map in `mathmate-v2/src/lib/textbookLicenses.ts`
already defines `geometry` (label + color) even though no catalog entry used it before, so
`geometry` could be used without any code change. Mappings:
- `calculus` — Ideas of Calculus
- `geometry` — Geometry; Art & Sculpture (origami, sliceforms, surfaces, symmetry)
- `number-theory` — Number Theory
- `discrete-math` — Games & Puzzles (combinatorial games); Truth, Reasoning, Certainty, & Proof (logic/proof)
- `other` — Dance, Music, Knot Theory (topology, no topology subject), Patterns, The Infinite
