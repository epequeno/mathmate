# 2026-10-08 — First publication, architecture review, two fixes

## Summary

The repository was pushed to GitHub for the first time (the remote had been created on 2026-09-01 but left empty). Preparing it for publication turned up two real defects and one larger piece of unfinished work.

## Publication

- Scanned all history for secrets (none) and removed a hard-coded home path from a test.
- Added screenshots and `docs/ARCHITECTURE.md`; linked `SECURITY.md` from the README.
- Both test suites pass: Vitest 272, `cargo test` 177 (1 ignored).

## Found and fixed

1. **`search_textbook` was never offered to the model.** The system prompt told the model to use it; the tool list built in `services/synapse.rs` did not include it. It is now a built-in tool, with tests that every offered tool has an executor.
2. **The system prompt lived in two places.** `lib/turn/prompt.ts` held a copy that nothing used, while `chatStore.ts` held the live one, and the two had drifted. `prompt.ts` is now the single source. Output was checked identical to the old inline assembly across 24 input combinations before the old code was removed.

## Found, not fixed

- **Unfinished service-layer migration** (Phase 14C): legacy flat modules coexist with `services/`. Plan: `Implementation_ServiceLayerCompletion.md`.
- **The graph-embedding instructions are not in the live prompt.** They existed only in the unused copy and are kept as the exported `GRAPH_INSTRUCTIONS`. Appending them would change model behaviour, so it needs a decision.
- **Olympiad tutor style drops the user's system prompt and retrieved memories.** Behaviour preserved and now pinned by a test.
- **Keys are handled in the webview**; OS keychain storage remains deferred (see `SECURITY.md`).
